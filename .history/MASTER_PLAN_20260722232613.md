```

│   ├── attendance/     # Điểm danh
```

## Lưu ý kỹ thuật quan trọng

1. **Migration strategy** — Backward compatible: frontend cũ vẫn chạy với localStorage cho đến khi backend hoàn thiện. Dùng feature flag để bật/tắt API mode.
2. **Versioning** — API versioning (`/api/v1/...`) để không break frontend cũ.
3. **TypeScript everywhere** — Share types giữa frontend và backend qua monorepo package.
4. **Security** — JWT refresh token, rate limiting, input sanitization, CORS.
5. **Testing pyramid** — Unit (nhiều) > Integration (vừa) > E2E (ít).
6. **Mobile-first** — Tiếp tục ưu tiên responsive, PWA cho mobile data saving.
